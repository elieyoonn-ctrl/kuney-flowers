# Bouquet photographs

Drop your KUNEY FLOWERS photographs into this folder, then point the wall frames
and featured cards at them from the admin panel (`/admin.html` → Displays).

Recommended:

- **Wall frames / shelf pieces** — portrait, 1200 × 1600px, JPG or WebP, under 400 KB each.
- **Landing hero** — landscape, 2400 × 1400px.
- **Featured cards** — square, 1000 × 1000px.

Reference them with a path relative to the site root, e.g. `images/peony-01.jpg`.

Any frame without a photo renders a soft plaster placeholder with the piece's
title, so the space always looks finished while you are still shooting.
